# ✦ AIverse – The Future Is Your Quiz

AIverse is an interactive quiz website where you can test your knowledge of AI, gaming, cybersecurity, and future technology. Choose a topic, answer questions, and challenge your brain!

explanation video=(https://drive.google.com/file/d/1lFYb4IKFsDIUs4yRrZGo7Fh1Tl7OrIe_/view?usp=sharing).

### 🚀 Features
- 5 quiz topics
- Interactive multiple-choice questions
- Timer for each question
- Score tracking and result summary
- Previous, Next & Skip options
- Responsive design for mobile and desktop

### 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

### 📚 Topics
- 🤖 AI & ChatGPT
- 🎮 Gaming & Internet
- 🔐 Cybersecurity
- 🚀 Future Tech
- 🌍 Pop Culture & World Vibes

### 🎮 How to Play
1. Select your favourite topic.
2. Start the quiz.
3. Answer the questions before time runs out.
4. View your score and play again!
